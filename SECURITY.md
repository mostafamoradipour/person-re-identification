# Security Policy

Please do not report security vulnerabilities in public issues or pull requests.

Send a private report to [mostafa.moradipoor73@gmail.com](mailto:mostafa.moradipoor73@gmail.com) with a description, affected files or versions, and steps to reproduce. Avoid including real personal data, private datasets, or credentials in the report. Please allow reasonable time for review before public disclosure.

This repository is an experimental research codebase; no supported release schedule is currently published.
