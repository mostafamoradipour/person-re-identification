# Person-Re-id

Person Re-id wants to efficiently and precisely Re-identify a person in a random camera view, which was detected before in another view and from another camera sensor. This is done by extracting a discriminative feature of detected box of that human an matching with the collected features of all persons detected before from all camera views in a wild multi-camera system, which are placed in deifferent locations or in a specific organization.
