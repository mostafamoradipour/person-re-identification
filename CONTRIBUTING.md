# Contributing

Thank you for considering a contribution to Person Re-Identification.

## Before you start

- Open an issue to discuss substantial changes or proposed model changes.
- For bug reports, include the command, dataset split and layout, environment details, and a concise error log. Never upload restricted dataset content.
- Keep changes focused and document any effects on training, evaluation, checkpoints, or result interpretation.

## Development workflow

1. Fork the repository and create a branch for your change.
2. Make the smallest focused change that addresses the issue.
3. Run the relevant training, evaluation, or utility checks available for the files you changed. Record the exact command and environment; large dataset experiments may not be reproducible by every contributor.
4. Update the README when a command, configuration option, or expected data layout changes.
5. Open a pull request with a summary, rationale, validation performed, and any dataset or hardware requirements.

Do not commit datasets, checkpoints, credentials, or generated training artifacts.
